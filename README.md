#Project Subject
I developed an environmental monitoring and logging system for cold food and pharmaceutical storage applications, 
utilizing the STM32L073Z-EVAL development board. Throughout the project, I implemented real-time tracking of 
temperature and pressure sensor data on both a TFT LCD display and a PyQt-based control panel, integrated threshold
control mechanisms, and designed an EEPROM data logging architecture.
